# MoodTrail

A beautiful, engaging web app that lets users track their daily mood through an interactive color wheel and creates stunning visual 'mood trails' over time. Users can:

- Pick their daily mood using an intuitive color wheel interface
- Add short notes and emojis to each mood entry
- View their beautiful mood pattern timeline
- Share their mood trails on social media
- Get insights about their emotional patterns

## Features
- Interactive color wheel for intuitive mood selection
- Gorgeous animations and transitions
- Progressive Web App (PWA) support
- Local storage for offline functionality
- Social sharing integration

## Stack
- HTML5 Canvas for color wheel
- CSS animations
- Vanilla JavaScript
- LocalStorage for data persistence
